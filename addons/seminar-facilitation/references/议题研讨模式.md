# 议题研讨：从发言到可核对的小结

共同议题讨论按“环节”推进；逐组答辩按“组”推进。可按明确目标组合，但每段各算时间并合并总账，不把每组汇报自动当成讨论课，也不强制教师先选模式。

## 设计环节

先把要讨论的核心问题写清。可用下面一种组织方法，也可以按实际议题调整；它们是思路，不是固定四环节标准。

| 思路 | 可能的顺序 | 适用情况 |
| --- | --- | --- |
| 因果 | 现象→可能原因→证据→方案取舍 | 为什么出现某现象、可怎样改善 |
| 概念 | 含义→边界→受影响者→判断条件 | 名词混用或范围有争议 |
| 立场 | 主张→支持证据→反例→修订主张 | 存在可比较立场 |

每环节写一个入口问题与可留下的产物，例如判断及理由、排序及标准、边界条件或待验证假设。不要求所有讨论都只有一个正确答案；只能回答“是”的问题可加“在什么条件下、依据是什么”。

环节数由目标、资料量和总时长决定。时间表必须包含准备、讨论、记录/小结、必要换场与收尾，不规定45分钟只能3个环节。参见Skill入口的统一时间公式。

## 开场建议

> 本场问题是____，与你们的____任务相关。今天需要留下的是____。
> 先用材料说发生了什么，再说自己的解释；反对时说明依据。发言时长、顺序和记录方式按本场议程执行。
> 我会区分“有人提出”“多人同意”与“尚待确认”。不要求今天所有问题都一致，有必要可保留分歧。

具体的单次发言限时、点名、手机使用和分组方式由教师按现场条件决定，不从本模板擅自增加课堂纪律。使用手机查材料的课堂不能机械要求所有屏幕朝下。

## 当讨论停住时

从刚才的具体词或原文出发，选择一层追问，不连续抛三个问题。

| 层次 | 示例问法 |
| --- | --- |
| 事实 | “记录里这一句描述了谁、哪一步、几次？” |
| 机制 | “你把A和B连起来，是依据哪条证据？还有什么解释？” |
| 取舍 | “在这个条件下只能保留一个目标，你们选哪个，为什么？” |

没有材料就先查资料或明确假设，不能因为希望有人接话而制造事实。需要思考时给短暂写作或组内交换时间，不把沉默本身解释为赞同或不会。

## 常见情况

| 情况 | 主持建议 |
| --- | --- |
| 抢话 | “先让这位把一句话说完，再给回应。” |
| 重复 | “与刚才相同的部分先记在一起，有没有新依据或不同条件？” |
| 过于抽象 | “给一个这份材料里出现的具体情境。” |
| 只有表扬 | “可以同意；请再说明支持它的依据或成立条件。” |
| 一人占用 | “这一点记下了，先听还没发言的组，再核对。” |
| 某组沉默 | “可以先写下一个待核问题，不要求现在给定论。” |
| 技术争论无法核实 | “列作技术待核，不让主持小结替代来源核验。” |

不同意见有价值，但不能用“说一个你不同意的”逼出不存在的分歧。

## 小结：三项归纳＋一句过渡，共四项

```text
共识：记录中已明确确认的意见；没有则写尚未确认。
分歧：实际出现的不同主张和理由；没有则写记录未显示明确分歧。
待定：当前最需要核对的一件事，说明哪里缺依据。
过渡：主持建议的下一个入口问题。
```

每项尽量一两句，长度服从保留条件、否定和少数意见。过渡是主持建议，不写成学生已经同意的下一步。已有议程的下一环节仍适合时，过渡接回它；需改议程就说是建议，并重新核对时间。

共识至少要有记录中的确认依据；几人分别提出相似主张也不自动等于全班确认。记录里只写“第三组认为”就写成该组主张，不升级为“大家认为”。没有分歧也不补造两方；不知道有没有达成一致，就明确待确认。

若某技术主张可能错误，不照搬为事实，也不在原归纳中偷偷改正。可以在四项之后另列“教师待核提示：原记录第__条需要对照__来源”，并保留其与学生发言的区别。只有用户要求短小结时，优先保留最影响使用的待核提示。

## 怎样给专家记录

提供本环节的问题与实际发言，按条目标注简短编号即可。关键词、原话或较完整记录均可，不强行压成8条或20字而丢掉条件。先去掉本次整理不需要的姓名、学号、联系方式；角色或组号仍可能识别个人，保留在教师受控范围。

例如一条记录可以写“R2：组A提出方案甲，但说尚未试用”；小结可引用R2作为依据。转写文本有错字或说话人不明时标出，不猜测身份或归属。

记录不足时输出能支持的部分，如“仅有一位发言，尚无法确认共同意见”。确需确认才补问，不用“少于3条不能做”阻挡教师，也不要求重新提供整场会议参数。

## 结束总结

按实际各环节记录收四项：已确认的共同意见、保留的分歧、未答问题、优先下一步。没有确认的栏目可以留明确缺口；没有分歧不等于没讨论，存在分歧也不证明教学效果。

下一步写“谁在何时做什么、用什么材料验证”，本场未确定执行人时标作建议，不自行指派学生或自动发送。用户只要某一环节的小结时，不附整套收尾、评分或完整议程。

## 本包的现场能力

教师可以把记录粘贴给当前对话，再使用生成的小结辅助主持。本包没有自动收音、会议监听、手机发言入口或多人研讨台代码；不承诺实时同步，不额外搭建服务器或群聊机器人。安装Skill不能证明这些能力可用。
