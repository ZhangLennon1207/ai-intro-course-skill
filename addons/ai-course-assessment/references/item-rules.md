# 题型规则与命题事故

## 一、什么考点用什么题型

| 考点性质 | 合适题型 | 不合适 |
|---|---|---|
| 术语、部件、公式符号 | 单选、判断、填空 | 简答（学生背一段话，判分主观） |
| 概念边界「它不是什么」 | 判断（放一个典型误解）、单选（辨析两项） | 填空（考不出边界） |
| 因果与机制 | 简答（「为什么」）、单选（给现象问原因） | 判断（二元化会把机制压扁） |
| 计算与套用 | 填空（单值）、计算题（过程） | 单选（过程看不见） |
| 方案取舍 | 综合分析题（给材料 + 要求比较） | 单选（压成一个正确项会失真） |
| 实验与工具 | 简答（说明步骤与变量） | — |

**判断题的陷阱**：一句话里有三处限定（「所有」「一定」「只要…就」），学生靠语气就能猜对错。合法用法是放一个学生真会有的误解，而不是玩反问。

## 二、四个层次怎么判（不是按难度，是按认知动作）

| 层次 | 学生要做的动作 | 题干长什么样 | 容易误判成 |
|---|---|---|---|
| 记忆 | 回忆、复述、认出 | 「……的定义是」「下列属于……的是」 | — |
| 理解 | 解释、举例、换说法 | 「为什么」「用自己的话说明」 | 记忆（把定义原文抄一遍也能得分） |
| 应用 | 套到新情境、算、判 | 给一个新数据/新场景，问结果 | 理解（场景其实和课上一样） |
| 分析 | 比较、归因、取舍、指出局限 | 「两种方案各适合什么情况」「失败最可能是哪一步」 | 应用（只是多算一步） |

判断口诀：**把课上原例换掉还能做，才是应用；要在两个都对的说法里选一个，才是分析。**

## 三、干扰项怎么设计

好干扰项来自真实的错误推理，不是把正确项改个词。五类可用：

1. **相邻概念**（把「监督学习」的答案放在「强化学习」题里）——考边界。
2. **因果倒置**（「因为过拟合所以数据少」）——考机制。
3. **条件缺失**（把「在数据线性可分时」拿掉）——考适用条件。
4. **计算常见错**（漏加偏置、链式法则少乘一项）——考过程。
5. **术语形近**（前馈/反馈、精度/召回）——考术语。

禁用：「以上都对」「以上都不对」「无法确定」——它们会把题变成二次判断，且常常出现两个正确答案。`--check` 会提醒。

四个选项里，正确项的位置要打散，别连续三题都是 B。

## 四、主观题评分细则（rubric）

写法：3–5 个给分点，每点一句可判断的话，分值加总等于题目分值。

```
【评分细则】
· 写出前向计算与损失计算（3 分）
· 写出反向传播求梯度（3 分）
· 写出参数更新（3 分）
· 给出两种停止条件并说明判据（3 分）
```

三条要求：

- **给分点是「做对了什么」，不是「提到了什么词」**。「提到链式法则给 2 分」会让学生堆术语。
- **允许替代路径**：同一结果用另一种方法算出来，同样给分；在 rubric 里写一句「等价方法同样给分」。
- **分档要能区分半分**：12 分的题分成 4 个 3 分点，比 1 个 12 分点好判得多。

## 五、常见命题风险

| 症状 | 后果 | 处置 |
|---|---|---|
| 四个选项有两个都对 | 学生申诉，送分 | `--check` 报「选项重复」只抓同文，语义重复靠人；出题后自己逐题选一遍 |
| 题干里带答案线索（「下列不属于深度学习的**浅层**模型是」） | 送分题 | 去掉限定词里的暗示 |
| 填空题一个空两个答案都成立 | 判分争议 | 改答案为「×/×」二选一，或加限定语 |
| 判断题全卷 5 题 4 个「×」 | 学生蒙对 | 对错比例大致 1:1，且不按固定节奏排 |
| 简答题 12 分只写「言之有理即可」 | 无法复核，学生不服 | 必须有分点 rubric |
| 题目依赖「上节课讲的例子」 | 缺课学生无法作答 | 材料写进题干 |
| 开卷卷只需查到原句 | 难以看到应用与解释过程 | 按实际课程目标选择认知动作，不预置固定比例 |
| 总分 98 或 102 | 教务退回 | `meta.total` 与逐题合计必须一致，脚本硬查 |

## 六、开卷考试的特殊约束

- 可带材料、设备和考试形式以实际课程说明为准，本包不预置“只许一本书”等规则。
- 题干给的数据要「书上没有」，否则学生在书上找到原例，抄一遍满分。
- 综合题要求跨两节以上，逼学生自己组织。
- 计算题可以给公式表，但要求说明「为什么用这个公式」。

## 七、复核记录要写什么

`build_paper.py` 自动生成，人工补三句：

1. 这套卷覆盖了细目表的哪几行、哪几行合并了。
2. 有意删掉的知识点及原因（课时不够 / 已在实验里考）。
3. 已知风险（某题可能有第二种解法、某题材料偏长）。
