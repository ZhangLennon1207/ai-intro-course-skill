# 给教师的安装与使用说明

本套件只用于《人工智能概论》教师项目。五位专家共用一个“人工智能概论教师助手”，帮助备课、命题、设计实验和准备课堂答疑。

## 第一次安装

把 `ai-intro-course-setup-1.2.0.zip` 或已解压的源码目录交给能读取文件的WorkBuddy Agent，说明目标项目：

> 请按安装包中的说明，把教师专家团和教师助手配置到我的“AI概论-教师备课”项目。能自动完成的直接做，保留原有配置，完成后核对专家和技能的登记、关联结果。

也可先在WorkBuddy“技能 → 添加技能 → 上传技能”导入安装包，再发起同一请求。安装Agent会自动完成平台支持的创建、更新和关联，无需逐个粘贴专家提示词，也无需选择教师/学习用途。账号登录、目标项目或资料权限缺失时，只会提示必要的一步。

源码仓库为私有。接收者需有仓库访问权，或由课程负责人提供安装包；不要把GitHub密码或密钥写进对话。

## 项目里选择什么

优先让安装Agent自动关联。需要使用“新建项目”界面时，“专家”选已登记的“人工智能概论教师专家团”或“人工智能概论课程主管”，“技能”选“人工智能概论教师助手”。无需把五位专家全部勾上。

“人工智能概论教师项目快捷安装”只负责配置与更新，不是日常备课时要选的教学技能。已有登记可能保留旧显示名称，安装Agent会按实际ID核对复用，不因名称变化重复创建。

如果只完成本地项目目录安装，平台登记与界面选择项仍需验证，不能直接当作全部安装完成。

## 接入课程资料

把本人有权访问的课程资料库链接或文档提供给安装Agent。平台支持时由它自动关联；确实需要手动操作时，在资料库选中空间或文档，点击“··· → 添加到任务”。

第一次可先让助手打开一份课件正文，返回文件名、实际章节或页码及内容概括。能看到目录、已经填入链接，都不代表正文已读到。资料库内容由登录账号的实际权限控制。

## 日常使用

| 需要什么 | 可以直接这样说 |
| --- | --- |
| 备课 | 结合课程资料，为经管和文法类学生设计单元7的90分钟课程，附完整活动材料和教师参考回答。 |
| 实验 | 根据第三章课件设计A*课堂实验，给出完整输入、教学步骤和教师参考结果。 |
| 命题 | 根据已讲内容新编6道练习，附教师答案、解析和评分要点。 |
| 答疑准备 | 为这节课准备学生可能问的5个问题、教师可用的解释和常见误解提示。 |

助手先检索课程正文，再完成本次任务。普通备课交一份完整教案，准确性检查融入成品；明确要求独立报告时才另交。需要分发讲义或练习题面时，可再要求导出一份去掉教师答案和内部内容的文件。

## 更新

把新安装包交给安装Agent，说明“更新这个教师项目的课程套件”。它会复用已登记资源、保留原资料入口和无关配置，遇到你修改过的内容时说明具体冲突。

题库、答案、内部资料及会话记录留在教师受控范围。反馈问题时提供版本、任务输入与具体偏差，不向公开讨论区粘贴保密内容。平台注册、选择器、真实检索和课堂效果，以实际回读和测试结果为准。
