# 教师模板的识别与适配

教师给模板时，"按模板来"不是把内容塞进模板的某一页，而是**继承它的规范，重排内容**。

先分清两条路——选错路径，后面怎么调都不像：

| 教师给的东西 | 走哪条 | 能做到 |
|---|---|---|
| 一份**含示例页的原始课件**（他自己上课用的那份） | **画像路径** `--template` + `--profile` | 版式保真，装饰全留 |
| 一份**空白模板**（单位发的、占位符齐全没用过） | **占位符路径** `--template` | 继承主题与版式，内容自绘 |
| 什么都没有 | 默认模板 | 一套干净的通用样式 |

**教师自己做的课件，绝大多数不是占位符驱动的。** 实测某原模板课件：28 个版式，实际讲课只用其中一个「空白」版式；整页底图、AI 角标、内容框、标题下横线全挂在这个版式的形状里；页面上有 3 个页脚占位符但一个都没填；标题是手画的圆角标签。这种文件用占位符接口去套，结果是「配色沾点边、位置全靠猜」。

## 一、画像路径（有原始课件）

```bash
python scripts/inspect_template.py 教师课件.pptx -o out/profile.json --assets out/tpl_assets
```

它读的不是「模板声明了什么」，而是「教师实际怎么排」，输出 `profile.json`：

| 字段 | 内容 |
|---|---|
| `meta` | 页面尺寸、正文页实际使用的版式名、各自页数 |
| `title` | 章节标签：几何、圆角类型、填充/描边、字体字号字距、出现的页与标签文本 |
| `page_title` | 页标题：几何、字号、字体（从跨多页重复的位置聚类得到） |
| `body` | 正文安全区：内容框内缩后的可用矩形 |
| `chrome` | 版式里的整页底图、角标、内容框、标题下横线、是否自带页码占位符 |
| `cover` / `end` | 整页底图、**角标图片与几何**、文字层级（按 y 排序） |
| `density` | 正文号中位数、每页字数中位数与 p90 |
| `fonts` | `title` / `body`：从 run 层面按字数加权统计出的**实际使用**字体 |

生成：

```bash
python scripts/build_deck.py 故事板.json out.pptx --mode A \
    --template 教师课件.pptx --profile out/profile.json --check
```

`--template` 给容器（母版、版式、主题、媒体），`--profile` 给几何与配色。少一个都会错。

### 页头是两层

```
上层 章节标签（圆角标签，居中，白字）   →「这是第几节」
下层 页标题（左对齐，加粗，比正文大）   →「这一页讲什么」
```

故事板里 `section` 给标签文字、`title` 给页标题；`section` 缺省回落到 `kicker`。只画一层的结果是全篇页标题都变成章节名，学生翻页找不到当前位置。

章节标签宽度固定，字数超了会被挤出圆角。`--check` 会按 `(标签宽 − 0.45) × 72 ÷ 字号` 算上限并报警。

### 四个必须按画像改、不能按直觉改的地方

1. **字体取「实际渲染的」，不取主题的。** 主题里常写着 `Calibri` / `Calibri Light`，中文实际回落成别的字体。取错的表现是标签里的中文变成默认宋体，一眼假。
2. **页标题必须比正文大。** 原件里标签 24pt、页标题 18pt、正文 14pt。照搬 18pt 而正文放到 24pt，就成了「标题比内容还小」。脚本按 `正文上限 + 5` 兜底。
3. **正文字号按教师密度夹紧。** 教师正文 14pt 就别放到 24pt。脚本取 `教师字号 × 1.35` 作为上限。
4. **封面校徽是一张独立的图，不在底图里。** 只铺底图会得到「有科技蓝背景但左上角空白」的封面。画像单独导出 `cover.logo` 与 `logo_geom`，必须贴上去。

### 其他从画像来的规则

- **页脚不要重复画**：模板版式里已有页码占位符时，再自绘一条页码线会重影。脚本检测到 `chrome.footer` 为真就跳过自绘页脚。
- **密度对齐**：教师每页字数中位数是硬参考。某课件 2 学时 20 页、每页约 72 字，说明他靠图承担信息。A 模式照这个密度排，别塞进 200 字。
- **封底用原件的整页底图和最大字号**（原件常是 54pt 居中「谢 谢 观 看」）。

## 二、占位符路径（只有空白模板）

```bash
python scripts/inspect_template.py 模板.pptx      # 只看版式清单与主题
python scripts/build_deck.py 故事板.json out.pptx --template 模板.pptx --mode B
```

1. **看比例**：13.333×7.5 是 16:9，10×7.5 是 4:3。按模板比例算栅格，不强行改。
2. **看示例页**：生成时会被清空，母版元素保留；**贴在页面上**的装饰会一起被清掉。
3. **看版式名**：中文常见 `标题幻灯片 / 仅标题 / 标题和内容 / 节标题`，英文 `Title Slide / Title Only / Title and Content / Section Header`。按名称匹配，匹配不到退回索引。

必须继承：`fontScheme` 的字体（`ea` 是中文字体）、`clrScheme/accent1` 的主色、`p:sldSz` 的页面比例。
可以重排：标题（写进占位符但强制左对齐）、正文（自绘，左边界对齐标题）、页脚（模板已有就不重复画）、图表宽度（不超过标题宽度）。

## 三、五种常见冲突

| 情况 | 处理 |
|---|---|
| 模板是 4:3 | 照 4:3 排，不要拉成 16:9。要点页自动降到 3–4 条 |
| 标题占位符在页面中间 / 有装饰框 | 保留位置，只填文字；内容区从占位符下沿算起 |
| 模板字体本机没装（如方正正大黑简体） | 仍按模板字体写进文件；渲染自检会看到替换效果，交付说明里提醒教师装字体 |
| 校徽/水印是「贴在示例页上」的图片 | 随示例页被清掉 → 走画像路径，它会单独导出并重新贴上 |
| 有 28 个版式但只用 1 个 | 正常。按 `meta.content_layout` 那一个来，不要按版式数量猜 |

## 四、没有模板时

用 `assets/default-template.pptx`：16:9、深蓝 #1F4E79、微软雅黑、统一页脚线 + 页码。
要换主色就重建：

```bash
python scripts/make_default_template.py            # 改脚本顶部的 ACCENT / CN_FONT 常量
```

## 五、交付时必须说清

- 用的是哪份模板（文件名），走的是画像路径还是占位符路径
- 哪些元素继承了（标签、页标题、正文区、配色、字体），哪些被重排了
- 字体是否本机具备
- 是否有渲染自检图（`render/contact.png`）
- 有没有"建议稿"前提（缺大纲/课时）
