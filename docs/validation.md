# 教师版验证范围

当前版本1.2.0，仅验证教师项目。文件检查、本地程序测试、离线内容观察与WorkBuddy实机验收分别记录。

## 文件与安装包

构建器检查五个原生专家、唯一教学Skill和安装入口的元数据、角色绑定、头像、完整依赖和ZIP内相对引用。安装清单只包含教师项目配置及主管与教师助手的推荐选择，不分发其他用途的配置。包的SHA-256与文件数记录在 `dist/build-report.json`。

本地环境文件、密钥、课程原件、题库与本地资料入口不进入分发包。两个Skill的通用字段以临时投影执行基础校验，WorkBuddy额外字段由构建器检查；这不是平台导入测试。

## 本地自动测试

结果见 [本地验证记录](../tests/local-validation.json)。测试覆盖默认教师安装、无需模式参数、旧教师安装升级、重复执行、资料入口保留、内容冲突、失败回退、打包排除，以及真实分发包解压后的安装。两个符号链接用例在当前Windows账号下因权限限制跳过。

对旧非教师安装目录仅保留拒绝改装的迁移保护，避免覆盖历史。恢复失败会报告具体路径和备份，不能据此承诺进程崩溃或断电时所有文件都能自动恢复。

## 教师内容与实机验收

[10个教师任务用例](../tests/eval-cases.json)覆盖备课、课件、实验、命题、课堂问答和分发稿；[5个安装用例](../tests/setup-eval-cases.json)覆盖自动配置与更新。实际执行状态见 [WorkBuddy记录](../tests/workbuddy-run-records.json)。

本次在隔离环境检查教师课堂问答准备，结果单独记录，不替代真实课程正文检索。旧教案观察保留为历史数据，不能写成本版通过。

平台专家登记、项目绑定、选择器显示、真实委派和课程正文读取仍需WorkBuddy实测。文件安装只记为 `filesystem_installed`，平台注册与运行验证保持未确认；未取得真实回读时不宣称勾选可用。
