# 控场话术

话术按本场议程调整。下面是可改写的建议，不是课堂纪律或评分规则，也不能暗示主持人已看到未取得的材料。

## 开场：只说这场已经确定的安排

> 今天在____分钟内完成____组汇报。各组陈述____分钟、追问____分钟；换场、休息和收尾已经列在议程中。
> 请先说清项目解决谁的什么问题，再用作品或具体记录说明做到了哪里。涉及应用前景时，说清现有替代、证据和边界。
> 到约定时间我会提醒，没讲完的问题记入待办。不能现场回答的，可以说明还没验证，避免临时猜。

开场实际时长与议程一致。若本场是正式答辩，不说“这不是考试”；若有评分，只宣读已确认的标准。未决定的安排不能在台词中写成已经宣布。

## 时间落后

| 情况 | 可以这样说 |
| --- | --- |
| 陈述还剩约定提示时间 | “陈述还剩____秒，请转到当前证据和下一步。” |
| 到陈述截止 | “我先接住这一点，转入刚才约定的追问。未展开的内容记入会后补充。” |
| 请求再延长 | “先按原时间完成，补充放在记录里；若全场有余量，再统一安排。” |
| 已经落后 | “目前比计划晚____分钟。需要在不改变已确认必留环节的前提下调整，剩余议程如下。” |

调整后重新加总剩余时间，给出对后续所有组公平的方案，不临时承诺“从提问扣一分钟”或让最后一组承担全部超时。教师有意延长时明确新的结束时间与影响。

## 冷场与参与

| 情况 | 可以这样说 |
| --- | --- |
| 问题过宽 | “先只说你们实际见到的一次情况：发生在哪一步？” |
| 组员等组长 | “先给大家半分钟看记录，谁负责这一部分就先说；其他人可以补证据。” |
| 有人持续沉默 | “可以先写一句，再由组内任选一位读；有不同意见也可以保留。” |
| 一个组占用过多机会 | “先记录这点，听一位还没发言的同学，再回来核对。” |

冷场也可能是材料不够、问题不清或需要思考，不断言学生“不准备”或“基本都会答”。技术问题只在本场目标和学生已学范围内追问，不把低门槛事实问法当成保证答得出来。

## 跑题、辩解与事实错误

| 情况 | 可以这样说 |
| --- | --- |
| 只讲行业趋势 | “先记下趋势判断。回到这个项目，哪一步发生了变化，有什么记录？” |
| 进入与本场无关的技术细节 | “这点单列技术待核。现在先回答议程中的____问题。” |
| “我们已经考虑过” | “那这次可以展示哪一条依据，尚未验证的是什么？” |
| “时间不够” | “按目前资源，只保留一个可验证动作，你们会选哪个？” |
| 引用教师意见 | “先对照实际要求，再看这项决定依据什么，不凭一句转述确认标准。” |
| 可能的事实错误 | “这句话需要核对来源。先标待核；主持小结不把它改成已确认事实。” |

接住表达不等于赞同内容。不要用“趋势我同意”“这个方向对”等未经证据的肯定替代核对，也不要替教师承认其未做过的承诺。

## 主持人自己的限制

一次点评尽量短，必要时先提一个问题再让学生回应。讨论不是让主持人连续讲授；技术纠正与学生意见分别记录。组间支持不贴“强组、弱组”标签，优先说明本组已经提供和仍欠缺的材料。

## 收尾：依据实际记录

> 今天已确认的是____；还需核对的是____。这些判断分别来自记录____，不是对全部项目的推断。
> 各组后续反馈采用“已经做到什么、主要卡点、下一步先做什么”。没有依据的内容保持待定，不临时给正式分。
> 下一步请在____前完成____，验证方式为____。没有统一任务时，各组按自己的具体卡点确定，不要求所有项目都“证据升一级”。

收尾时间与议程一致，不预设大多数小组停在哪个等级。需要会后另留时间时先取得主持教师安排，不能在脚本中自动承诺下课后10分钟或替教师向学生发送通知。
