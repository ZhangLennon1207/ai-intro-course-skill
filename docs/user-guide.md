# 给使用者的快捷配置与使用说明

本套件把《人工智能概论》的五位专家和一个课程 Skill 一起交给 WorkBuddy 配置。日常使用时，只需在课程项目里提出备课、出题或学习问题。

## 第一次安装

把课程安装包交给 WorkBuddy，并说明要配置到哪个项目、用于教师备课还是学生学习。例如：

> 请阅读安装包中的安装配置说明，把课程专家团和课程 Skill 安装到我的“AI概论-教师备课”项目。优先自动完成安装和关联，保留项目原有配置；完成后检查专家和技能是否实际可选，再告诉我还缺什么。

使用安装 Skill 包时，先在 WorkBuddy「专家·技能·连接器 → 技能 → 添加技能 → 上传技能」导入 `ai-intro-course-setup` 安装包，再发上面的安装请求。也可以把已解压的项目源码目录交给能够读取本地文件的 WorkBuddy Agent，让它按仓库首页链接的安装配置说明执行。

安装 Agent 会先检查当前 WorkBuddy 支持哪些管理能力，再自动完成它能做的专家创建、技能安装和项目关联。需要你选择项目、完成账号登录或申请资料权限时，才说明具体缺少哪一步。无需逐个粘贴专家提示词。

本套件的源码仓库为私有仓库。接收者需要能访问仓库，或由课程负责人提供安装包；安装 Agent 不会索要 GitHub 密码或访问密钥。

## 创建项目时选什么

安装 Agent 能关联现有项目时，会直接完成关联。需要你使用“新建项目”界面时，按下表选择；不需要把五个专家全部勾上。

| 用途 | “专家”中选择 | “技能”中选择 |
| --- | --- | --- |
| 教师备课 | 已注册的“人工智能概论课程专家团”或“人工智能概论课程主管” | “人工智能概论课程助手” |
| 学生学习 | 已注册的“人工智能概论课程答疑” | 同一个“人工智能概论课程助手” |

“课程快捷安装”用于配置和更新，不是日常教学时需要勾选的课程技能。如果安装结果显示“仅完成项目目录配置”，说明 `.codebuddy` 文件已写入，但平台列表是否出现、项目是否绑定还未验证；不要把它当作全部安装完成。

## 接入课程资料

把本人有权使用的课程空间或文档交给安装 Agent。它会在平台支持的范围内关联资料；无法自动关联时，会指出所需操作。平台要求手动添加时，在资料库找到空间或文档，点击「··· → 添加到任务」。

教师项目使用教师受控资料，学生项目只关联学生可读资料。选择“教师模式”只是选择工作方式，不会给账号增加资料权限。安装 Skill、填写链接也不会自动获得知识库的访问权。

师生请使用独立项目和目录，不把用过教师资料的项目改名或切换模式后交给学生。更新备份和历史也可能保留内部内容；安装器会阻止在同一目录跨师生用途切换。

## 配置好后怎样使用

| 需要什么 | 可以直接这样说 |
| --- | --- |
| 备课 | 结合课程资料，为经管和文法类学生设计单元7的90分钟课程，附完整课堂活动材料和教师参考回答。 |
| 实验 | 根据第三章课件设计A*课堂实验，给出完整输入、学生步骤和教师参考结果。 |
| 命题 | 根据已讲内容新编6道练习，分别给学生题面和教师参考答案。 |
| 答疑 | 我不理解A*里g(n)和h(n)的区别，请结合课程例子解释，再给一道新编自测题和解析。 |

课程助手会先检索相关资料、读取正文，必要时补查，再完成你要的内容。普通备课交一份完整教案；准确性检查融入成品，只有明确要求时才另出专项报告。

第一次使用可先让它找一份课件正文，返回文件名、实际章节或页码和内容概括，再开始正式任务。返回“资料已关联”不等于正文已经读到。

## 更新与反馈

将新安装包交给安装 Agent，说明“更新这个项目的课程套件”。它应复用已登记资源，保留无关配置，遇到你自行修改过的同名内容时先说明差异，不重复创建一套专家。

反馈时提供安装版本、项目用途、任务输入和具体问题。教师题库、答案及含内部内容的会话记录留在受控范围，不贴到公开问题讨论中。

本版提供了安装材料和自动配置流程；当前客户端能否完成全部注册、是否出现在项目选择列表、真实资料检索和师生权限，都以实际安装回读和测试结果为准。
