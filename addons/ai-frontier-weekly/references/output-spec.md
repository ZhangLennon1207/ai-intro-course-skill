# 周报产出规范

## 日期与文件

默认使用项目时区Asia/Shanghai，以本周周一的日期作期号；覆盖窗口为实际检索截止时刻之前7×24小时。用户指定其他期号或窗口时遵从并写明。期号不是每条新闻的发生日期，检索时间也不能替代事件日期。

| 位置 | 用途 |
| --- | --- |
| `outputs/AI前沿周速递-YYYYMMDD.md` | 本期Markdown |
| `outputs/AI前沿周速递-YYYYMMDD.html` | 同期离线网页 |
| `weekly-site/index.html` | 本期站点工作副本，不代表已上线 |
| `weekly-site/assets/` | 本期原图本地化结果及manifest |
| `outputs/assets/` | 仅复制manifest中本期图片，供输出HTML离线打开 |
| 项目根 `AI前沿周速递-最新.html` 与 `assets/` | 需要离线最新入口时更新，只管理本期文件，不整目录覆盖 |

图片使用 `ai-frontier-YYYYMMDD-N.jpg` 前缀。所有本地HTML和MD的图片引用都用相对路径。没有图片时不要保留空img或虚构图源。生成器不能覆写未知来源的同名文件；已有受管稿可按更新要求改，同期保留教师自改内容并说明冲突。

上一期从 `outputs/` 与 `参考资料/周速递/` 中按合法日期找早于本期的最近 `AI前沿周速递-YYYYMMDD.md`，不要查找带“上一期”字样的文件名，也不要用包内样稿充当实际历史。

## 正文结构

```markdown
# AI前沿周速递

**期号：YYYY-MM-DD** ｜ 覆盖：起止时刻与时区 ｜ 检索于：实际时刻 ｜ 面向：人工智能概论授课教师

> 本期说明：窗口、条数与覆盖缺口；本稿为教师备课材料。

## 一、计算机 / 电子信息类
### 1. 主体＋动作的事实标题
**事实**：事件日期、主体、已核对事实。厂商自测或研究限制要归属。
**对本专业的意义**：可用在哪个知识点或课堂案例，说明这是教学分析。
**课堂讨论点**：
1. 一个可比较立场或操作判断的问题。
2. 另一个问题。
**信源**：T1/T2＋已印证/未交叉印证，按实际情况写。
**来源**：到篇链接，而非首页。

## 二、其他理工类
## 三、经管 / 文法类
## 四、艺术 / 外语类

**本期配图情况**：正文N条、配图M条；其余未配原因。
**信源覆盖**：未检索到合格更新与未取得正文分别列出。
自动化产出仅为原材料，最终采用与否由授课教师判定。
```

目标8–12条、每类至少2条。没有合格消息的分类保留标题及原因，不用存疑条目补数。每个正文条目要有两个真实可讨论的问题；同一事件多来源合并，不重复计数。

来源必须支持紧邻的事实，未披露数据写未披露。不要把“已交叉印证”“官方发布”“指定公众号”混为一个可靠性等级，不用笼统的“官方模型卡”为未核对数字背书。

## HTML与离线检查

沿用 `assets/weekly-report-template.html` 的CSS与四类结构，替换所有日期、正文、标签及 `{{...}}` 占位。该模板没有真实新闻，不能直接当周报交付。历史样稿的事实和格式不自动满足当前规则，不能照抄其数字、图片或单问题条目。

需要图时可用下列片段；图片文件必须在当前HTML对应的assets目录，图注写真实来源和日期，不把占位文件名留进成品。

```html
<figure class="fig"><img src="assets/ai-frontier-YYYYMMDD-1.jpg" alt="原图信息简述" loading="lazy"><figcaption><b>图源</b>来源机构，原文日期，原文链接；内部备课使用。</figcaption></figure>
```

运行配图检查脚本，图必须可解码；外站图片或路径越界属于失败。无图是允许的结果，页脚明确说明，不宣称“所有线上图片已验收”。输出MD、HTML及必要图片，并给真实文件链接；工具没有文件展示能力时返回实际路径，不能编造下载地址。

## 发布与结果口径

生成本地文件不等于发布。用户明确要求发布或已授权持续更新时，先核对目标站点、公开范围和图片使用条件，再用实际发布能力执行。不能从固定目录推断一定复用旧网址；更新需真实站点ID及部署回读。旧站点、访问码和凭据只保留在用户本地受控配置，不进源码、模板或示例。

发布后按实际URL检查线上图片及首页当前期号；本地检查不能证明线上内容更新。没有发布能力时交本地成品并说明，定时任务也可照常产出内部文件，不为缺少站点而中止整个周报。
