# 周速递信源配置

本文件是可选起始模板；未创建时可直接使用Skill内置信源规则。复制到项目 `参考资料/周速递/信源配置.md` 时，只创建缺失文件，不覆盖教师已有配置。

- 服务对象：《人工智能概论》授课教师。
- 四类专业：计算机/电子信息、其他理工、经管/文法、艺术/外语。
- 检索方向：大模型、具身智能、AI治理伦理、AI教育。
- 默认优先：可核对到篇原文的机构官方、研究/监管一手资料，以及有出处的原创报道。
- 教师额外指定信源：暂未指定，使用内置范围；可在对话中要求添加关注名单。
- 每期逐个检查已指定信源；无法取到正文时记录访问缺口，不推断没有更新。
- 默认只产出教师项目内的MD与HTML，不公开发布，不推送消息。

本文件只设置关注范围和写作偏好，不授予账号、发布、发送或定时执行权限。
