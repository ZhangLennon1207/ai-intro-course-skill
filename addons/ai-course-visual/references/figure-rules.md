# 选型决策与常见事故

## 一、决策树（三十秒内定下来）

```
要讲的东西有几个？
├─ 1 个 → 是概念名词吗？
│        ├─ 是 → card 知识卡
│        └─ 不是（是一个数、一条结论）→ 不做图，写句子
├─ 2–6 个，之间有顺序
│        ├─ 单向推进 → flow
│        └─ 会回到起点 → loop
├─ 2–6 个，之间有包含关系 → tree
└─ 2 个以上方案要比 → compare
```

两个以上的答案同时成立时，**拆成两张图**。一张图承担两个关系，读者只记得住其中一个。

## 二、五类图的做法

### flow（流程图）
- 纵向排，箭头一律向下。横向排只适合 3 步以内、且页面是宽屏。
- 每个节点：动词短语（「求和加偏置」），不是名词（「偏置层」）。流程讲的是动作。
- 节点 3–5 个最好，超过 6 个拆成两张。
- 分支不要画：一个节点引出两条路会让布局算法失效，改用两张图 + 文字说明条件。

### loop（闭环）
- 节点 3–4 个，顺时针。
- **必须闭合**，缺最后一段的闭环是这五类里最常见的错误——读者会以为流程停在那里。
- 中心放一句「这一圈叫什么」（「一轮训练」），比在环上写满字清楚。
- 环上不要标注「重复 N 次」这类数字；那是文字信息，放图注。

### tree（层级图）
- 只画两层半：根 → 分支 → 分支下的要点。三层以上用大纲，不用图。
- 同一层的分支必须**同一维度**（输入/隐藏/输出是层，不是「数据/算法/效果」）。
- 子项每条 ≤6 字，超过就合并。

### compare（对比矩阵）
- 第一列是维度名，后面每列一个方案。
- **列头必须同维度**：不能一列写「前馈网络」，另一列写「适合做分类」。
- 行数 3–5 行最好；超过 6 行改成分段文字，读者看不完。
- 差异用文字写，不用颜色暗示「哪个更好」——教学图不做推荐。

### card（知识卡）
- 一卡一概念。正面概念名（≤10 字），下面定义一句、易错一句、记法一句。
- 定义必须能独立读懂，不写「见课件第 8 页」。
- 「不是」这一行是卡片的价值所在：学生记错的地方就在这里。

## 三、配色

只用三个语义色，含义固定：

| 色 | 含义 | 用错的表现 |
|---|---|---|
| `main` 深蓝 #1F4E79 | 主体、当前讲的这条线 | 把所有节点都涂成一个颜色 → 看不出重点 |
| `compare` 青 #2E8B8B | 另一方案、对照项 | 用来标「错误」→ 语义冲突 |
| `warn` 红棕 #B03A2E | 易错、风险、需要停一下 | 用来做装饰 → 读者以为这一块有问题 |

不用渐变、阴影、立体效果。深色底不用（打印会糊）。

## 四、图注模板

```
读图顺序「自上而下 / 顺时针 / 按列比」：<一句话说明关系>。<示意/实测/出处>
```

三种常见图注：

- 流程：「读图顺序自上而下：从输入到输出共四步，第三步之后才产生误差信号。示意，不含具体数值。」
- 对比：「按列比：左列是前馈网络，右列是反馈网络，每行是同一维度的对照。」
- 知识卡：「一卡一概念，正面概念名，背面定义与易错点。」

## 五、常见事故

| 症状 | 原因 | 处置 |
|---|---|---|
| 图里的字在 PPT 上糊成一片 | 出图时按 16:9 满宽设计，插进页面被缩到 60% | 字号按最终尺寸的 1.5 倍设计，或拆图 |
| 节点文字顶到框线 | 只按字符数判断，中英文混排宽度差一倍 | 用字宽估算（全角 1、半角 0.55），留 10% 余量 |
| 箭头扎进盒子里 | 箭头端点取的是节点中心 | 取矩形边界交点，箭头停在框外 |
| 闭环图没闭合 | 少画最后一段箭头 | 闭环必须首尾相接，缺一段就是流程断头 |
| 对比表两列不同维度 | 想到什么写什么 | 先定维度行，再填两列 |
| 图注写「示意图」但带具体数字 | 数字来自估算没标 | 标「示意」，或换成有出处的实测值 |
| 一张图讲了三件事 | 想省版面 | 拆三张；一图一关系 |
| SVG 打开字变体 | 引用本机字体，换机器没有 | 交付说明里写清字体，或转路径 |

## 六、交付清单

| 文件 | 用途 | 检查 |
|---|---|---|
| `fig_xxx.png` | 插 PPT/Word | 200dpi，缩到页面宽度后字仍清楚 |
| `fig_xxx.svg` | 后续改字改色 | 用浏览器打开一次，确认不乱码 |
| 配图计划 json | 复用与批量重出 | 与课件故事板 `figure` 页的 `image` 字段对应 |

课件故事板里 `image` 填 `figs/fig_xxx.png`，`build_deck.py` 会按故事板所在目录解析路径；找不到会渲染成灰框。
