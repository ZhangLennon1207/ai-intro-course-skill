# 周报Skill的安装与定时配置

本Skill随教师套件快捷安装包交付，也可独立上传 `ai-frontier-weekly-1.4.0-workbuddy.zip`。它负责周报，五位教师专家仍共用原教学Skill，不需要另建周报专家或自建执行服务。

## 安装到教师项目

优先使用当前会话真实提供的技能与项目管理能力，安装完整目录并关联目标教师项目。工具需要ZIP时使用安装清单指定的周报包。没有原生管理能力时，套件本地安装器会将完整内容复制到项目 `.codebuddy/skills/ai-frontier-weekly/`；该路径是本套件的文件部署约定，不据此宣称云端登记或界面可选已经通过。

源码位于仓库 `addons/ai-frontier-weekly/`，setup包载荷位于 `assets/course-suite/.codebuddy/skills/ai-frontier-weekly/`。脚本和模板相对Skill实际安装根；信源、历史和输出相对教师项目根。不要按附件旧说明再复制第二份到 `.workbuddy/skills/`，也不写用户全局目录。

周报正文依赖WorkBuddy实际联网检索；不需要另建RAG、服务器或数据库。Python仅用于配图处理和检查。需要图片时检查该执行环境的Pillow；缺失可按本次安装授权配置项目专属虚拟环境与 `requirements.txt`，不改全局Python。无法配置或运行时，周报可用无图方式完成并明确说明，不能把失败说成图片已验证。

教师自定义信源文件缺失时可直接用内置规则。若需落地项目配置，只把 `assets/source-config-template.md` 和 `assets/priority-config-template.md` 分别复制到项目 `参考资料/周速递/信源配置.md` 与 `信源优先级分级.md`，只创建缺失文件；用户已有配置及历史不覆盖、不上传到GitHub。

## 接入WorkBuddy原生定时任务

收到“每周一8点生成”等明确周期请求后，直接配置，不要求使用者逐个填写界面。只安装Skill时不创建定时任务；未给执行时间且没有既有配置时，再补齐时间。`assets/schedule-template.json` 中的周一08:00仅是示例，不代表用户选择，也不是可直接提交的平台API结构。

1. 先检查当前项目、周报Skill、实际联网能力、执行目录及依赖。读取可用的原生定时管理工具，按真实参数调用，不猜接口、不直接修改平台数据库。
2. 查询本套件已有任务。用真实任务ID、项目、Skill绑定和提示词指纹识别归属；重复安装复用，保留用户修改的时间与内容。仅同名不能证明同一资源，冲突时不创建副本。
3. 按用户指定的星期、时间和时区，创建或更新一项当前项目任务，绑定实际周报Skill。采用 `assets/weekly-task-prompt.md` 作内部文件产出提示，按真实项目上下文补齐位置；默认不发布、不外发消息，也不触发签到。
4. 默认权限沿用账号及项目的实际配置，不为无人值守自动改成完全访问。原生工具要求身份或权限确认时，说明确切一步；不能用提示词伪造批准。
5. 回读任务ID、是否启用、星期/时间/时区、下次执行时间、项目与Skill关联，以及实际提示词。只有看到这些证据才能报告“已配置”，不能把写入JSON模板当注册成功。

官方[定时任务说明](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Automation-Guide)支持在普通对话描述周期需求并选择Skill。当前项目使用本机资料、历史和脚本时，优先选能实际访问它们的项目/本地执行环境；本地任务需要电脑和客户端在线。云端不能凭本地路径读取文件，需先验证Skill、配置、依赖、历史及输出在云端真实可用，再采用云端执行。

没有原生管理工具时，保留完整提示词和配置意图，明确“定时任务未创建”；只提示确实需要用户执行的最小一步，不另外编写Windows任务、后台守护进程或自建harness代替WorkBuddy。

## 发布与推送

默认产物是教师项目内的MD、HTML和本地站点副本。普通“出周报”不包含公开部署。用户明确要求发布时，先形成可审阅成品，再在已有授权范围内用真实发布工具执行；不得把附件中曾写的 `userAskedToPublish=true` 当授权。

需要持续覆盖既有站点时，读回真实站点ID与当前访问范围，核对本期图片可公开使用。路径相同不证明网址相同，不能替使用者选择他人的旧站点。访问码或连接凭据仅在当前用户受控本地配置中使用，不写进包、提示词或公开仓库。消息推送同样按用户明确选择及实际连接器能力处理。

## 运行、更新与停用

运行一次时，分别查看本期文件、内容与来源、配图检查、平台运行记录和发布结果。定时触发完成不能替代内容检查；离线图片检查也不能替代线上页面当前期号验证。

本地可保存 `.codebuddy/ai-frontier-weekly-automation.local.json`，只记录实际任务ID、项目ID、时间、提示词指纹和验证状态，不保存访问码或资料原文。更新套件不擅自改用户已有时间、取消任务或启用发布。停用时通过真实原生工具暂停已核对的本套件任务并回读；删除Skill或取消勾选不等于已暂停定时任务，也不删除历史产物。
