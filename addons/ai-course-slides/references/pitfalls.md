# 踩过的坑：症状 → 原因 → 处置

这份表是实际做过单元 3（深度学习基础）四版课件、跑过一份原模板教师原件画像之后攒下的。
**遇到症状先查这里，别重新推导一遍。**

## 一、版式与模板

| 症状 | 原因 | 处置 |
|---|---|---|
| 全篇页标题都是章节名 | 只画了章节标签一层页头 | 页头两层：`section` 给标签、`title` 给本页主题 |
| 标签里的中文变成宋体、一眼假 | 字体取了主题里的 `Calibri` | 从 run 层按字数加权统计真实字体（`inspect_template.py` 已做） |
| 标题比正文还小 | 照搬了原件的页标题 18pt，正文却放大到 24pt | 页标题下限 = 正文上限 + 5（脚本兜底） |
| 正文比原件"空"很多 | 教师正文 14pt，被放到 24pt | 正文上限取 `教师字号 × 1.35`，夹在模式区间内 |
| 封面有科技蓝背景但左上角空白 | 校徽是**独立贴图**，不在整页底图里 | 画像单独导出 `cover.logo` + `logo_geom`，封面必须贴 |
| 页码出现两条 | 模板版式里已有页码占位符，脚本又自绘一条 | `chrome.footer` 为真就跳过自绘 |
| 装饰全丢，只剩白底 | 装饰挂在**示例页**上，清空示例页就一起删了 | 走画像路径，从版式层复刻 |
| 配色沾边但位置全错 | 教师的课件不是占位符驱动的（28 个版式只用 1 个空白版式） | 别用占位符套，读画像 |

## 二、渲染与排版

| 症状 | 原因 | 处置 |
|---|---|---|
| 文字压到页脚 / 小结句跑到框外 | 行距按 1.35 估，PPT 行距是乘在 1.2em 行高上的，低估了 | 估算用 `1.2 × 倍距`；结论句收进 `body_bottom − 0.42` |
| 四张卡片横排被压成竖条 | 4 列时每卡只有 2 英寸宽，中文自然折成一列 | 超过 3 张改两行两列 |
| 卡片里「、」「，」跑到行首 | 窄卡片靠自然折行，标点被甩到下一行开头 | 卡片文字用 `\n` 显式断行 |
| 卡片拉满页高，下半全是白 | 卡片高度取了整个可用区 | 按内容需要给：单行上限 3.4 in、两行按最大卡片的文字行数算，不要直接取 `(可用高 − 间距) / 2`；两行时底部再留 0.12 in，否则第二排底边紧贴内容框 |
| 卡片页写了 takeaway 却不显示 | summary 原先只画卡片、不画结论句 | 现在 summary 会画；别的页型写了 `--check` 会点名 |
| 整页下半空，看着内容稀 | 内容装不满时行距固定不变 | 余量摊进段间距（最多 1.15 倍），仍不满则整块居中 |
| 图页是个灰框 | `image` 路径写错；脚本把图名里的 `-` 换成 `_` | `fig_loss-curve` → `fig_loss_curve.png`；`--check` 会报缺图 |
| 图页上出现一块白方块，跟底色割裂 | 配图存成白底 PNG，贴在浅色内容框上就是一个白矩形 | `make_figures.py` 一律 `transparent=True`；外来图先抠底 |
| 引文页整页变成封面风格，正文压着花纹看不清 | `quote` 无条件铺封面底图 | 有画像时引文页走内容页版式（`new_content_slide` + `draw_head`），留在内容框里 |
| 页头只剩标签、没有页标题 | 页型没写 `title`，`draw_head` 直接 `KeyError` | 引文/图页也要给 `title`；`draw_head` 已对缺 `title` 容错 |
| 公式下标变成方框 | 用了 Unicode 下标 `₁`，微软雅黑缺字形 | 用 `$x_1$` mathtext，或 OOXML baseline |
| 页面上的公式原样显示 `o_j`、`Σ_k` | 故事板里没包花括号，上下标语法没触发 | 写成 `o_{j}`、`Σ_{k}`；`--check` 会报「裸上下标」 |
| 上标被读成函数调用 `W(1)` | 用了 Unicode 上标 `⁽¹⁾`，字体缺字形被降级成括号 | 用 `^{...}` 语法，脚本写 `baseline` 属性 |
| 生成的文件 PowerPoint 报损坏 | `buFont` 排在 `buChar` 后面；或英寸/EMU 重复换算 | `buFont` 必须在 `buChar` 前；尺寸直接用 EMU ÷ 914400 |

## 三、内容与覆盖

| 症状 | 原因 | 处置 |
|---|---|---|
| 页数够了但内容明显少 | 按**页型**写成了「9 种页型各来一遍」，不是按知识点 | 一知识点 1–2 页；`coverage_check.py` 会点出没人讲的知识点 |
| 知识点清单查不到落点 | `coverage` 只是给人看的清单，没和 slides 关联 | 在承载页写 `"covers": ["知识点名"]`；`covers` 写**主讲**，不写"顺带提到" |
| 覆盖率报了 3 个假漏讲 | 字面匹配；通识版标题本来就是大白话（「一个圈，转很多遍」＝训练闭环） | 以 `covers` 为准，字面匹配只当提示；报告会标"疑似" |
| 顺序检查刷一屏假警报 | 主线页和小结页顺带提到所有概念 | 顺序检查只认 `covers` 声明的主讲页 |
| 从知识库抽的标题顺序错乱 | chunk 是语义召回，**没有页序** | 有本地 pdf 就用 `--pdf`（页序可信）；只有节点时人工复核节序 |
| 抽出来的"标题"其实是正文首句 | 只按字号判定 | 五重判定：上部 1/3 + 长度 ≤24 + 不以标点收尾 + 非纯符号 + 层级路径栈 |
| 章号对不上 | 教师常沿用另一本教材的章号（单元 4 的课件叫「第2章」） | 按**知识点**对齐，不按章号 |
| 照抄了教师课件页数 | 那是累积版，100 多页含习题与备用页 | 按模式页数区间重排，删减写进差异清单 |
| 文件名叫「对齐某某」，内容其实是自己那套顺序 | 拿 B 版故事板套上教师模板，只换了皮没换骨架 | A/C 必须**按教师页序重写故事板**；`diff_deck.py` 会算出原件每页有多少字进得了新课件，低留存页逐条核 |
| 教师术语的英文缩写丢了（FNN、FBNN、BP） | 改写措辞时只留了中文 | 教师在台上会用缩写，学生笔记也要记；术语首次出现写全「中文（缩写）」 |

## 四、流程与工具

| 症状 | 原因 | 处置 |
|---|---|---|
| 知识库里的 pptx/pdf 下不下来 | `export-node` 的 kind 只支持 `doc`/`database`/`web` | 不是权限问题。正文已入库，可检索；要版式必须让用户给本地文件 |
| `workbuddy-pdf` CLI 报 `cannot read`（exit 4） | 该 PDF 结构特殊 | 改用 PyMuPDF（fitz）直读，项目里已验证 |
| 本机预览字体不对 | 商用字体未安装，PowerPoint 静默回落 | **只影响预览，不影响交付**：文件里保留原名，交付说明写一句（`font_check.py` 会报） |
| 过拟合示意图外发散成贴边直线 | 高阶多项式拟合真实数据，边界外炸开 | 改成可控叠加正弦 |
| 一页 5 条要点挤成 4 条 | 缩小字号硬塞 | 拆页。`--check` 按模式报要点数与字数上限 |

## 五、必须核对、脚本查不出来的

1. **教师课件的知识顺序**是否与我们排的页序一致（尤其用知识库节点还原时）。
2. **公式与符号写法**是否跟教师一致（教师写 $\sigma$ 还是 `sigmoid` 是小节，但符号体系不能换）。
3. **案例是否属于本班门类**（非 AI 专业从 07 案例库对应门类取，库里没有就说明缺口）。
4. **渲染图**是否逐页看过（`render/contact.png`）。没看过不算做完。
5. **A/C 的差异清单**是否逐条核过（`diff_deck.py`），「几乎没讲」那一档要给出"有意删/漏了"的结论。

## 六、自检报出来的东西怎么读

| 症状 | 原因 | 处置 |
|---|---|---|
| `--check` 报一堆，页面看着却没问题 | 规则按**显示宽度**判（中文 1、ASCII 0.55），公式一条约 30 宽 | 通常报的是真问题。照文案改，每条都写了改法 |
| 要点被判超 40 字宽 | 一条里塞了两句话 | 拆两条，第二句进 `note` 当讲稿；别缩字号 |
| 「故事板写 mode=B，本次按 --mode D 生成」 | 故事板与命令行给了两个模式，深度规则换了一套 | 确认哪个是本意，去掉多余的那个。不修就是「标着通识版、实际专业深度」，外人看不出来 |
| 「出现数学推导符号 ∂」 | C/D 是降深版，混进了推导 | 换类比或直接给结论。概念名（"激活函数的作用"）可以留，符号不行 |
| C 档讲公式被拦下 | 检测按 D 的标准算，C 其实允许留 1–2 个式子 | C 按**页**给额度（前 2 页），D 零额度；「链式法则」只在 D 里算越界——它是教师课件的知识点，C 必须能讲 |
| 「章节标签 N 字超出宽度上限」 | 标签圆角宽度固定，字多会拆行 | 缩标签文字，全称放正文第一句 |
| 差异清单里「几乎没讲」一大片 | A 模式只套了模板、没真沿用人家的内容 | **这是有用的信号**，逐条补内容；不要调低阈值把它压下去 |
| 差异清单按标题对不上 | 教师课件整章共用一个页头标签（20 页只有 5 个不同标题） | 脚本已改成「章节并列 + 内容落点」，别改回逐页标题对齐 |
| 本机提示字体未安装，其实装了 | 注册表里叫 `Microsoft YaHei`，中文名精确比对查不到 | 别名组已打通；新字体加进 `font_check` 的别名表 |
| 空字体名被判「未安装」 | 空值当成了查不到 | 已改为空名直接通过——没指定字体不等于缺字体 |
| 教师说「AI 味太重」但说不出哪里 | 他自己也描述不了，只知道不像人写的课 | 跑 `voice_check.py` 把话说明白：每页都收结论（T1）、标题成片对仗（T4）、要点等长（P2）——这三条占八成 |
| 去 AI 味后句子变空 | 为了降分把信息删了，或加了「非常」「进一步」凑语气 | 分数降下来是结果不是目标。改法见 `de-ai-voice.md` 第一节：先保信息，再谈像不像人 |
| 术语被当成 AI 味报出来 | 「训练闭环」「链式法则」命中了词表 | `coverage` 里的知识点名自动进白名单；不在 coverage 里的术语加到 `meta.terms` |
| 单句对比句被报 A1，可它是对的 | 「不是被教规则，是被给例子」在纠正真误解 | humanizer-zh 的保留边界：两部分都提供信息就留。改的是**成片**，不是单句 |
| `spine` 页只有流程图没有可背的话 | 没写 `mnemonic` | 补一句顺口的；没有它这页只是插画 |
| `recall` 页问了不揭晓 | 没写 `answer` | 学生记住的是自己的错答案。答案小字压在页底，投影时最后再露 |
| 年表页被报「三条一样长」，可它是对的 | 「1998 LeNet…／2012 AlexNet…」四行同构是格式要求，`P2` 当成凑节奏 | v1.7.2 起按「年份 / ①②③ / 1. 开头」自动豁免。**别为了让规则不响去砍短一行**——误报比漏报更坏，它会让人改坏正确的东西 |
| 图页全变灰框，`--check` 说「没跑 make_figures.py」 | 图片路径按当前工作目录解析，换个目录跑就断 | 已改为按故事板目录解析；先确认 `figs/` 在故事板旁边，再怀疑缺图 |
| 补了记忆骨架，反而报「页数不在建议区间」 | 页数把 spine/recall 也数进去了 | 区间只数讲授页（v1.7.1）；改了别忘 C/D 也复跑一遍 |
| 速记卡「每节只留一句」显示的是页标题 | 该节第一张内容页的 takeaway 被减密删掉了，逻辑直接退回标题 | 已改为整节里找第一个有结论句的页，全节都没有才用标题 |
| 回问页提示贴卡片底、答案压在卡片外沿 | 卡片高度按正文区拉满，答案用固定偏移落位 | 卡片改成固定高度、整块居中（v1.7.1）；答案另起一段画 |
| 回问页在页头重复了一遍提问 | `draw_head` 按 `title` 画页标题，卡片里又画了一次 | 已在 `slide_recall` 里对页头传入空标题，只保留章节标签；别再手动加回来 |
