# 课程依据与使用范围

当前项目固定服务教师教学；分发版是产物类型，不是身份或权限模式。课程名称、单元、受众、学时、成绩和考试规则，以当前项目有权取得的实际课程正文及教师明确要求为准。本包不预置某所学校的安排、教材章节映射或成绩权重。

先复用本次已提供的信息，再用WorkBuddy当前实际可用的检索和文档工具读相关正文。目录、节点ID、文件名和其他Agent所说的“已读”不是正文证据；不能从本机隐藏路径调用猜测的库接口。缺正文时说明具体缺口，示例文件不能填充为课程事实。

输出区分引用、自拟示例和未核对信息，来源定位用真实章节、页码或标题；抽取不能确认页序时不要编页码。输入文件与课程原件只读，修改正式资料、发布、推送或变更权限另按用户明确请求及实际工具权限处理。

assets中的JSON、示意图和知识点表均为DEMO，仅用于运行和格式示例。项目中已有知识点编号应跨课件、讲义、题库和学情保持一致；没有当前项目映射时不自动采用包内单元3示例。普通备课不自动运行全部技能或添加专项报告。
