# 课程资料定位说明

本包保存教师教学方法，不保存完整课程知识或内部资料。资料以运行时实际附带的 WorkBuddy 正文为准。优先使用教师项目已有资料和教师给出的入口，不把未知公开范围的共享邀请链接写入分发包。

## 找什么资料

先看当前空间的导航和索引，再按主题查正文。旧资料曾采用以下分类，可作检索词，不能据此断言当前目录完全相同：索引与维护、政策与安排、教材、论文、课件、题库、实验、案例、FAQ、工具。

正式课程安排可按文件名搜索《2026秋〈人工智能概论〉课程安排与教学结构_权威版》和《2026秋〈人工智能概论〉实验与实践安排_权威版》。这些是历史导出中出现的候选文件名，批准状态、当前版本及正文仍需核实；不要用旧序号定位现行资料，也不预填学时、成绩比例或发布日期。

用户按单元号提问时，先定位当前安排中的单元名称、范围和对应课件，再依正文设计；不能把旧示例中的主题固定套用到所有任务。

## 不同任务需要的最小证据

| 任务 | 优先资料 |
| --- | --- |
| 课程政策/学时/考核 | 当前批准的安排正文和变更通知 |
| 教案/活动 | 章节课件、对应教材，必要时课程目标 |
| 实验指导 | 当前实验指导及任务要求，环境/提交规格 |
| 命题 | 当前教学目标和范围；抽题时还须实际获准的现行题库 |
| 技术核查 | 待审原句、教材、原始论文或官方技术文档 |
| 课堂答疑准备 | 当前课件、教材、教师提供的疑问及相关例题 |

## 外部核验起点

需要技术核验且课程材料不足时，围绕本次具体问题检索原始论文或官方文档。读取相关内容后再作为依据，不预设每次都要查询的技术主题或论文清单。

历史文献不支持“当前最强”“最新产品支持”等时效结论。当前能力另查当期官方资料；没有联网或正文时缩小结论，明确哪项待核。
