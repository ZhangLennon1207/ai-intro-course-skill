# 人工智能概论教师专家团

1.5.0原生套件包含课程主管、教学设计、AI领域、出题评测、课堂答疑准备五个专家，全部绑定一个“人工智能概论教师助手”。五项制作Skill、AI周报与签到随快捷安装包独立提供并按能力关联项目，不包含在此专家团ZIP中。主管按交付物路由，主笔读取真实可用的制作Skill；普通提纲和少量练习不扩成全流程。

优先使用同版本的 `ai-intro-course-setup` 安装入口，让WorkBuddy Agent按实际管理能力自动登记资源并关联教师项目。没有相应管理能力时如实报告，不把项目文件部署称为平台登记成功。本包是开放平台格式资产，不代表已上架市场或已在账号中注册。

项目通常选“人工智能概论教师专家团”或“人工智能概论课程主管”，以及“人工智能概论教师助手”。旧显示名称可依实际资源ID复用，不重复创建。资料权限仍由账号和空间配置控制。

说明与源码：https://github.com/ZhangLennon1207/ai-intro-course-skill

`settings.json`与`setting.json`使用相同主管设置，兼容官方网页和示例包的命名差异；具体效果须在客户端验证。
