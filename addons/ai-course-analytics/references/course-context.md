# 课程口径与项目上下文

课程事实来自教师当前项目中实际有权读取的大纲、课件、教材、实验和考核说明。先检索正文，保留可核对来源；目录、题名或别的助手说“已读”不能代替正文。

本包不预置某校、某学期的权威学时、比例、教师名单、课程安排或知识库节点。学校名称、考试方式、可用资料、评分规则及班级信息以本次任务和实际项目文件为准。旧样例的单元3不代表当前任务必须是单元3。

已有信息先使用，缺小项可给明确建议值；涉及正式范围、总分、评分政策的关键缺项不能伪造。教师用途不等于身份认证，访问以当前账号与工具权限为准，正常备课不额外设学生模式或暗号。

输入、生成产物与教师答案留在指定项目。创建文件不包含公开发布、外发消息、修改正式题库、更新成绩或更改权限，除非有具体操作请求与真实工具授权。
