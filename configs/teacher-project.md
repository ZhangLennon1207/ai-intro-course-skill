# 教师项目指令

安装Agent优先把下面内容合并到目标项目的独立受管区段，保留其他指令。资料入口只填写用户指定且账号有权访问的地址；未提供时可先完成安装。

```text
course_id: ai-introduction
course_mode: teacher
course_materials_entry: 填入本教师项目有权访问的课程资料入口

本项目用于《人工智能概论》教师教学工作，使用ai-intro-course教师助手。
按本次需求检索课程正文，完成备课、课堂活动、实验、命题、案例或课堂答疑准备。
主管按需组织专家；普通备课只交完整成品，不固定增加独立核查报告。
只读取当前账号和工具实际准许的资料。题库、标准答案与内部讲义可在有权时用于教师任务，产物留在受控范围。
需要分发材料时再单独导出，去掉教师答案与内部内容，不分享整个保密会话。
修改正式材料、发布或更改权限，按用户具体指令和工具实际授权处理。
```

这些字段是本套件的项目指令约定，不是平台API或身份凭据。资料关联与正文读取需要实际核对；安装不授予额外权限。
