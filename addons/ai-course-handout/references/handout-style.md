# 讲义版式与写法细则

## 一、内置版式（可调整默认，不是学校强制规范）

| 元素 | 字号 | 中文字体 | 其他 |
|---|---|---|---|
| 文档标题 | 三号 16pt | 宋体 | 加粗、居中、段后 6pt |
| 副标题（课程/读者） | 10pt | 宋体 | 灰色 #595959、居中 |
| 节标题 | 四号 14pt | 宋体 | 加粗、左对齐、段前 10pt |
| 正文 | 小四 12pt | 宋体 | 1.5 倍行距、首行缩进 2 字符、两端对齐 |
| 概念行（术语加粗） | 小四 12pt | 宋体 | 不缩进，术语与定义之间空一个全角空格 |
| 边界说明（它不是什么/边界） | 小四 12pt | 宋体 | 左缩进 0.74cm（约 2 字符） |
| 易错点/练习 | 小四 12pt | 宋体 | 不缩进，用（1）（2）编号 |
| 符号表 | 11pt | 宋体 | 三线表或全框线，列头加粗 |
| 来源行 | 小五 9pt | 宋体 | 灰色，不缩进 |
| 页脚 | 小五 9pt | 宋体 | 居中页码 |

**首行缩进必须是「字符」不是「厘米」**：`w:ind w:firstLineChars="200"`。写成 `first_line_indent = Pt(24)` 的后果是——学生把正文改成五号字，缩进看起来变成 2.5 字符；老师一眼就看出来不是按规范排的。

## 二、五段的写法

### 1. 一句话结论
先说这节解决什么问题，再展开。判断标准：把这句话单独拎出来发给缺课的学生，他能知道这节在讲什么。

- 好：「判断是不是深度学习，看两点：够不够深，特征是不是自己学的。」
- 差：「本节介绍深度学习的基本概念。」（没有信息，只是目录）

### 2. 概念解释
三件套：定义 / 它不是什么 / 边界（适用条件）。

「它不是什么」是最容易被省掉、也最影响理解的一段。学生把「人工神经网络」当成「电子版大脑」，就是因为没人告诉他这两者的差别在哪。

边界写「什么时候不成立」，不写「适用范围广泛」这种话。

### 3. 例子
一正一反。反例的价值大于正例：正例只证明「这样行」，反例才划出边界。

反例必须写清为什么失效。用类比必须写明类比在哪失效——「梯度下降像下山」在非凸损失面上就失效，因为下山只有谷底，损失面有一堆局部低洼。

### 4. 易错点
写学生真实会犯的错，来自三处：作业里的高频错误、课堂提问的重复困惑、概念名称相近导致的混淆。

不写「注意理解」「认真掌握」「加强练习」。这类句子对复习零帮助，`--check` 会点名。

### 5. 练习
2–3 题，覆盖至少两个层次：

| 层次 | 检验什么 | 例 |
|---|---|---|
| 复述 | 能不能说出定义与要素 | 「写出人工神经元的三个计算步骤」 |
| 应用 | 能不能套到新情境 | 「给定权重和输入，算出输出」 |
| 辨析 | 能不能区分相邻概念 | 「感知机与逻辑回归是不是同一个模型？差在哪」 |

教师版可按任务提供完整参考解答与评分依据；学生分发版把练习答案分离，不因教师需要完整答案而拒绝生成。

## 三、难度分档

| 读者 | 公式 | 推导 | 例子来源 |
|---|---|---|---|
| AI 类（计算机/软件/电子/自动化） | 保留完整形式与符号 | 保留关键步骤（改变结论的那几步不能省） | 可用模型内部机制 |
| 其他理工 | 保留最终形式 + 符号表 | 只给结论与直觉 | 用工程或生活场景 |
| 经管/文法/艺术/外语 | 只留最终形式并注明可跳过 | 不推导 | 用本专业场景，如「绩点预测」「文献分类」 |

同一章的不同版本，**核心概念与结论必须一字不差**，只调表征方式和推导深度。这一点是复核时的第一检查项：拿两个版本对着看结论段。

## 四、来源标注

- 每节末尾一行「来源：」，写到章节号（如「教材 4.1 节」「教师课件 06 第 7–12 页」）。
- 全篇末尾一张「来源对照」表：讲义位置 → 依据。
- 教材没有、自己补的内容，正文里标「补充说明」，并给出处；不要混在教材内容里。
- 没有稳定页码就写章节标题。**不猜页码。**

## 五、交付清单

| 文件 | 给谁 | 检查 |
|---|---|---|
| `讲义_单元N_教师版.docx` | 教师 | 五段齐、答案要点在、来源对照表在 |
| `讲义_单元N_学生版.docx` | 学生 | 搜「答案要点」应为 0 处 |
| `讲义_单元N.md` | 预览/入库 | 与 docx 同源同序 |
| `讲义源_单元N.json` | 后续维护 | 改内容改这个，重跑脚本 |

## 六、常见事故

| 症状 | 原因 | 处置 |
|---|---|---|
| 缩进看起来比 2 字符宽 | 用了固定 pt 而不是 `firstLineChars` | 改 `w:ind@firstLineChars=200` |
| 中文字体在别人机器上变成宋体英文衬线 | 只设了 `font.name`，没设 `w:rFonts@eastAsia` | 四个属性一起设：ascii/hAnsi/eastAsia/cs |
| 学生版里带着答案 | 用同一个 json 直接出两版，没加 `--student` | 必须分别生成，搜一遍「答案」 |
| 表格跨页断在行中间 | 没设「允许跨页断行」为否 | Word 里表格属性→行→取消勾选 |
| 讲义读起来像 PPT 讲稿 | 把 `note` 整段搬进来了 | note 是嘴上说的话，只留书面结论 |
