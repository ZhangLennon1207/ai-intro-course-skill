# 项目研讨主持手卡

按完整议程压缩成可随手查看的一页内容；不是另排一套时长。以下项目/组行按实际增减。

**主题/阶段**：____　**总时长**：____分钟\
**开场**：____分钟　**收尾**：____分钟　**休息/换场/缓冲**：____\
**总账**：____＝____分钟，与正式议程一致。

## 开场稿

> 今天完成____。每组陈述与追问时间按表执行，剩余____时我会提示。\
> 请区分已经完成、目前证据和后续计划。不能回答的先记为待核，不现场猜。\
> 这场最后要留下____；如有评分，采用已经确认的____标准，没有就不临时打分。

## 追问备选

- 谁在什么具体场景遇到这个问题？不要报真实姓名。
- 现有替代是什么，相比之下哪一点改变了？
- 这份证据能支持哪条主张，不能支持什么？
- 哪一步实际完成，什么条件下还不能成立？

按材料选用，不要求每组问完。L0假设、L1意向、L2试用反馈、L3持续使用仅是证据线索，不能直接当正式分数或市场证明。

## 控场短句

| 发生什么 | 可说什么 |
| --- | --- |
| 到陈述时间 | “先转入约定的追问，未展开的内容记为补充。” |
| 冷场 | “先说材料里的一个具体情况，发生在哪一步？” |
| 跑题 | “这点单列待核，现在回到议程中的____问题。” |
| 防御或不确定 | “先说已经验证的部分，其他保留待定。” |
| 机会失衡 | “这一点已记录，先听还没发言的组。” |

需要调整时间时重算剩余总账，不单独挤占后续组的追问。教师事实补充与学生原话分开，不把礼貌回应当赞同。

## 收尾稿

> 本场有依据的共同问题是____，对应记录____；尚未确认的是____。\
> 会后反馈写“已经做到什么、当前卡点、下一步优先一件”。后续动作____、时间____；未约定的部分明确作为建议，不自动发通知或写回成绩。

无全体共识时如实说明，不预设“今天大多停在L1”。只要评议时，从实际记录提炼，不凭想象补事实。
