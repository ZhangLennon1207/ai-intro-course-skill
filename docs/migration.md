# 1.2.0教师项目简化

本版只保留教师用途，移除另一套项目模板、用途选择和切换流程。课程检索、备课、命题、实验、案例与课堂答疑准备继续由五位专家共用一个Skill完成。

五个专家和Skill的稳定标识保持不变，便于升级已有登记。“课程答疑”调整为教师的“课堂答疑准备”，不再承担独立学习端。新显示名称是“人工智能概论教师专家团”“人工智能概论教师助手”；平台不支持改名时保留已有名称，不仅因显示名称变化创建副本。

已有教师项目可按记录中的资源ID、版本和内容指纹更新，保留课程资料入口与无关配置。旧学生安装目录不自动迁入本版，请另用明确的教师项目；安装器不会清理或移动原目录。

安装入口 `ai-intro-course-setup` 只用于配置和更新，日常使用 `ai-intro-course`。有原生管理能力时自动登记、关联；只有文件部署时如实报告已完成范围。实际检索仍需取得正文，正常备课只交需要的成品，不增加固定专项报告。
