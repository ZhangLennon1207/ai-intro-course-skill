# 人工智能概论课程专家团

本原生套件包含课程主管、教学设计、AI领域、出题评测、课程答疑五个专家定义，以及一个共享课程Skill。它是WorkBuddy开放平台格式的专家团资产包，不代表已上架市场或已在使用者账号中注册。

希望快捷配置时，优先使用同版本的 `ai-intro-course-setup` 安装Skill：让WorkBuddy Agent读取安装说明并使用实际可用的管理能力创建专家、安装Skill及关联目标项目。没有管理能力时如实列出缺口，不把文件部署称为选择器注册成功。

项目中通常选择课程主管/专家团和课程助手Skill；学生项目选择课程答疑和课程助手。用途由项目指令配置，资料访问由当前账号及空间权限控制，安装不会代替身份授权。

说明与最新源码：https://github.com/ZhangLennon1207/ai-intro-course-skill

本包保留内容完整的相对文件路径。`settings.json`符合当前网页规范；`setting.json`与官方示例包一致，两份设置相同用于兼容，尚需客户端实测。不得据此宣称当前用户已完成安装或真实委派。
