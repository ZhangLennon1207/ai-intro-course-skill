# 教师版验证范围

当前版本1.6.0，包含六位专家、教学与研讨入口、五项制作能力、周报与签到。文件检查、本地程序测试、离线内容观察与WorkBuddy实机验收分别记录。

## 文件与安装包

构建器检查六个原生专家、团队使用的教学与研讨Skill和安装入口的元数据、角色绑定、头像、完整依赖和ZIP内相对引用。原主管ID、唯一lead、原五位的教学绑定与新增主持绑定分别核对。团队ZIP、独立研讨ZIP与完整安装载荷逐项一致。包的SHA-256与文件数记录在 `dist/build-report.json`。

签到Skill随快捷安装包及独立ZIP交付，不绑定教学专家，不默认开启后台操作。打包检查固定上游提交和三个原文件的SHA-256；`.gitattributes`固定这些文件的LF换行，避免Windows检出后哈希变化。

周报包包含完整HTML、脚本、依赖说明与原生定时提示模板。检查源ZIP与所有嵌套ZIP，原附件旧部署地址和访问码均未分发。原CSS逐字保留，模板中的未核对新闻替换为占位；历史样稿标为未核验的格式参考，不作本期事实或去重数据。

五项制作包包含完整脚本、依赖、规则和审查过的示例。仅在明确的Skill目录放行空白PPTX及示例CSV，其他学生数据、教师模板与课程原件不分发。三份知识点示例字节相同且编号唯一，未被当作实际课程映射。源码和独立ZIP、嵌套ZIP、安装载荷的文件与哈希逐项核对。

新增研讨包实际包含角色、头像、方法、四份参考与四份模板。附件外部说明提到的多人研讨台代码未在ZIP中，不能记作已实现；内含版本原为1.1.0，不能把外部说明的2.0.0宣传当执行证据。集成后统一使用职能名称，已扫描全部ZIP及嵌套文件，确认没有旧人名，也没有模型配置或课堂数据库。

本地环境文件、密钥、真实课程原件、内部题库与本地资料入口不进入分发包。十个Skill的通用字段以临时投影执行基础校验，WorkBuddy额外字段由构建器检查；这不是平台导入测试。

## 本地自动测试

结果见 [本地验证记录](../tests/local-validation.json)：91项中89项通过，两个符号链接用例因当前Windows账号权限限制跳过。使用项目专属虚拟环境，依赖见requirements-dev.txt。覆盖教师安装、升级、重复执行、入口保留、内容冲突、失败回退、打包排除，以及真实分发包解压后的受保护安装。

对旧非教师安装目录仅保留拒绝改装的迁移保护，避免覆盖历史。恢复失败会报告具体路径和备份，不能据此承诺进程崩溃或断电时所有文件都能自动恢复。

新增用例核对旧五专家回执升级为六位、原主管与无关文件保留、新专家同名未受管文件在写入前阻断、研讨方法完整安装及私有运行数据排除。分发测试回读实际六位专家和两个团队Skill，确认完整参考、模板、头像和绑定一致。文件安装子进程有审计保护，禁止执行配套Skill、启动子进程或联网。

签到的19项测试使用隔离目录与模拟调度器，核对锁定源码、任务归属、重复安装、冲突、失败恢复、卸载和依赖缺失。另在真实Windows PowerShell中用内存函数替换所有任务命令，检查跨日期触发器与JSON序列化；这没有注册真实任务。不访问真实凭据，不调用签到接口。课程文件安装同时部署附加Skill，但不执行其中代码，并排除缓存、环境文件和本地日志。

周报配图12项测试使用生成的真实图片字节与模拟HTTP/DNS，核对CDN域名边界、跳转来源、图片大小、解码、相对路径、无图和缺失依赖。线上检查不向外站发送访问码；测试未联网或部署。分发测试还验证周报HTML、两份脚本和依赖完整安装，以及教师改过的模板不被覆盖。

制作类8项测试实际生成PPTX、分离的教师/学生DOCX、含可编辑文字的SVG和200dpi PNG，并检查自定义知识点映射、缺失原生检索、全局依赖安装拒绝及既有渲染图片保护。13项出题/学情测试验证错误试卷不预写、量规配置、知识点重复拒绝、缺考/0分/未评、只总分模式、已知D值、选项分布、原始异常合并拒绝和不带个人ID的汇总。数据均为隔离示例，不是实际学生成绩。

## 教师内容与实机验收

[10个教师任务用例](../tests/eval-cases.json)覆盖备课、课件、实验、命题、课堂问答和分发稿；[18个安装用例](../tests/setup-eval-cases.json)加入研讨专家、时间核算、共识证据和实时能力边界。实际执行状态见 [WorkBuddy记录](../tests/workbuddy-run-records.json)。

保留1.2.0隔离环境中的教师课堂问答观察，不替代真实课程正文检索，也不记成本版新增通过。1.3.0另作安装说明的离线行为推演，覆盖用户暂不开启与明确开启签到两种请求；修正源码路径和拒绝后不再追问的措辞。旧教案观察保留为历史数据。

平台专家登记、项目绑定、选择器显示、真实委派和课程正文读取仍需WorkBuddy实测。文件安装只记为 `filesystem_installed`，平台注册与运行验证保持未确认；未取得真实回读时不宣称勾选可用。

本机Windows任务注册及真实签到也未执行。附加功能需要在接收端以实际任务读回、日志与业务返回分别验收；不能把静态审查或模拟测试写成奖励到账。

本次没有执行真实周报新闻采集、WorkBuddy定时创建或公开发布。配置模板不能记作真实任务ID，图片离线测试也不能证明线上页面已更新。

独立离线行为推演还检查了安装但不启用任务、周一08:00仅内部产出，以及无联网时只有历史样稿三个场景；关键说明与包内载荷一致，没有将文件部署、模板或历史稿冒充真实执行结果。

1.5.0另作四个入口推演：少量练习、复用上下文制作文件、总分不能推断知识点，以及教学图不能冒充周报原图。没有实际Office渲染或WorkBuddy原生调用；结构与内容隔离检查不证明所有字体、版式、课程事实或命题质量已验收。

1.6.0独立离线拟稿验证了90分钟8组的约束：开场5、收尾8、换场7、每组陈述5，得到每组追问3分45秒，17段连续议程合计5400秒。三条发言的小结没有编造共同意见；缺失多人研讨台时如实说明，原有3道练习请求仍走原流程。这是内容行为观察，不代表WorkBuddy注册、消息回传或真实课堂运行通过。
