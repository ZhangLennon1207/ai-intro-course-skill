# 隐私与分发检查

脚本只检查常见邮箱、手机号、会议号、角色后的姓名及本项目显式配置的敏感名称。包内没有真实教师名单。`deid.configure(names)`可为当前处理指定姓名；只对本次输入生效，不把姓名写回公开Skill。

模式检查和文档元数据清理不能证明全文匿名化。学生标识、学号尾号、文件名、截图、备注、页眉页脚和叙述上下文仍可能识别人；不能把保留学号的明细叫匿名数据。

教师卷含答案与评分细则，学生卷只交题面。分发前核查具体文件与隐藏内容，不能分享整个含内部答案的会话。个人成绩与原始CSV留在教师受控目录，默认分析报告仅聚合，不生成排名、自动公开链接或外发。

报告命中敏感模式时只记类型和待处理位置，不再次复制实际联系方式到复核文件。原始输入保留，处理规则和实际检查范围如实说明。
