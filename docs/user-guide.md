# 给教师的安装与使用说明

本套件只用于《人工智能概论》教师项目。五位专家共用一个“人工智能概论教师助手”，帮助备课、命题、设计实验和准备课堂答疑。

## 第一次安装

把 `ai-intro-course-setup-1.5.0.zip` 或已解压的源码目录交给能读取文件的WorkBuddy Agent，说明目标项目：

> 请按安装包中的说明，把教师专家团和教师助手配置到我的“AI概论-教师备课”项目。能自动完成的直接做，保留原有配置，完成后核对专家和技能的登记、关联结果。

也可先在WorkBuddy“技能 → 添加技能 → 上传技能”导入安装包，再发起同一请求。安装Agent会自动完成平台支持的创建、更新和关联，无需逐个粘贴专家提示词，也无需选择教师/学习用途。账号登录、目标项目或资料权限缺失时，只会提示必要的一步。

源码仓库当前公开，可直接取得源码或Release安装包；课程资料权限仍独立控制。安装不需要把GitHub密码、密钥或WorkBuddy登录凭据写进对话。

## 同时开启自动签到

本包会一起安装独立的“WorkBuddy自动签到与成长中心”Skill。要一并开启后台运行，把安装请求换成：

> 把教师专家团、教师助手和自动签到Skill配置到我的“AI概论-教师备课”项目，同时开启本机自动签到与成长中心。我了解它会读取本机登录态并使用已有补登卡、抽奖机会和能量。能自动完成的直接做，完成后核对项目和后台任务。

WorkBuddy会检查现有Python和Windows任务，自动配置每天签到及成长中心补查。无需填写计划任务界面、复制token或提供密码。课程安装与后台开启分别记录，某一项缺少条件不阻止另一项完成。

它会接收成长任务、领取服务器已标记完成的奖励，并操作旅行礼物、补登、连登兑换、抽奖和Buddy；不会替你完成聊天、编程、邀请、分享任务。本版只提供这套完整功能。只安装Skill不会启动后台操作，下载文件也不会默认开启。

停用时说“卸载自动签到后台任务，保留日志”。只取消勾选Skill不等于移除Windows任务。运行时间、来源、账号动作和兼容性范围见[详细说明](../addons/workbuddy-auto-signin/references/usage.md)。

## 项目里选择什么

优先让安装Agent自动关联。需要使用“新建项目”界面时，“专家”选已登记的“人工智能概论教师专家团”或“人工智能概论课程主管”，“技能”选“人工智能概论教师助手”。无需把五位专家全部勾上。

周报是独立的“AI前沿周速递”Skill，安装Agent会一并安装并关联教师项目；需要手动补选时，在技能里选择它即可。签到Skill独立提供，开启后台任务仍按前面说明处理。

五项制作Skill也随包部署并按平台能力关联：课件、讲义、出题组卷、学情分析、教学配图。日常仍直接把需求交给主管，不用每次手工切换专家或全部技能；确需补选时按这次交付物选择。五位专家的固定绑定仍是共享教学入口，不增加同名专家。

“人工智能概论教师项目快捷安装”只负责配置与更新，不是日常备课时要选的教学技能。已有登记可能保留旧显示名称，安装Agent会按实际ID核对复用，不因名称变化重复创建。

如果只完成本地项目目录安装，平台登记与界面选择项仍需验证，不能直接当作全部安装完成。

## 接入课程资料

把本人有权访问的课程资料库链接或文档提供给安装Agent。平台支持时由它自动关联；确实需要手动操作时，在资料库选中空间或文档，点击“··· → 添加到任务”。

第一次可先让助手打开一份课件正文，返回文件名、实际章节或页码及内容概括。能看到目录、已经填入链接，都不代表正文已读到。资料库内容由登录账号的实际权限控制。

## 日常使用

| 需要什么 | 可以直接这样说 |
| --- | --- |
| 备课 | 结合课程资料，为经管和文法类学生设计单元7的90分钟课程，附完整活动材料和教师参考回答。 |
| 实验 | 根据第三章课件设计A*课堂实验，给出完整输入、教学步骤和教师参考结果。 |
| 命题 | 根据已讲内容新编6道练习，附教师答案、解析和评分要点。 |
| 答疑准备 | 为这节课准备学生可能问的5个问题、教师可用的解释和常见误解提示。 |
| 周报 | 生成这周的AI前沿周速递，按四类专业组织，先保存本地MD和HTML。 |
| PPTX | 根据这份课件制作实际PPT，保留模板，受众与时长沿用前文。 |
| Word讲义 | 整理本章可打印讲义，学生稿去掉答案，教师参考另存。 |
| 成套试卷 | 按这些知识点制作40分小测，附分值覆盖表、教师答案和评分依据。 |
| 学情 | 分析这份实际作答表，说明缺失、缺考、未评分和样本限制，给出有证据的改课建议。 |
| 教学图 | 把这段关系做成SVG与PNG，文字可改，标明示意。 |

助手先检索课程正文，再完成本次任务。普通备课交一份完整教案，准确性检查融入成品；明确要求独立报告时才另交。需要分发讲义或练习题面时，可再要求导出一份去掉教师答案和内部内容的文件。

实际文件制作需要对应Python依赖。安装Agent可在项目专属环境配置所需依赖，不改全局环境；缺少Office渲染、模板或正文时应具体说明，不能把结构检查说成视觉检查已经通过。已有受众、时长和用途不会再次必问，只补齐确实影响结果的内容。

连续做课件、讲义、试卷和学情时可共享项目 `参考资料/课程结构/knowledge-points.csv`，已有编码沿用，没有则保留输入中的名字与ID。包内单元3表只是演示，不会自动套给其他章节。真实成绩及逐人明细留在教师项目，默认学情报告给汇总；只有总分就不会推断知识点掌握度。

## 每周自动生成周报

> 每周一北京时间早上8点，在这个教师项目生成AI前沿周速递，保存Markdown和HTML，不公开发布，也不外发消息。

WorkBuddy会在真实原生管理能力可用时创建或更新一项项目定时任务，核对实际ID、时间、Skill关联和下一次运行。这里的周一8点是使用示例，可以换成你希望的时间；安装包本身不会替你决定或开启计划。缺少管理能力时，它应说明未创建，并提供确实需要的最小操作。

周报默认检索最近7天公开原文，目标8–12条；消息不足就说明，不用过期样稿凑数。每条含课堂意义与两个讨论问题，原图可取则本地化，缺Pillow或图片不合格时可交无图稿。缺少你自己的信源名单也能用内置规则开始，已有名单与历史保留。

默认只生成内部文件。需要发布网页或推送消息时再明确指定，已有定时任务的时间和公开范围不会因为升级而改变。暂停周报时直接说“暂停这个项目的AI周报定时任务”，不能只取消勾选Skill就当任务已经停用。详见[周报安装与配置说明](../addons/ai-frontier-weekly/references/workbuddy-setup.md)。

## 更新

把新安装包交给安装Agent，说明“更新这个教师项目的课程套件”。它会复用已登记资源、保留原资料入口和无关配置，遇到你修改过的内容时说明具体冲突。

题库、答案、内部资料及会话记录留在教师受控范围。反馈问题时提供版本、任务输入与具体偏差，不向公开讨论区粘贴保密内容。平台注册、选择器、真实检索和课堂效果，以实际回读和测试结果为准。
