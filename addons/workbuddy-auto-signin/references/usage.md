# 自动签到附加功能的安装与停用

此附加Skill随课程安装包提供，也可单独导入 `workbuddy-auto-signin-1.5.0-workbuddy.zip`。安装Agent能完成的配置直接完成，不要求使用者手动填写Windows计划任务。

## 会发生什么

完整功能每天00:05运行一次，并在01:00、05:00、09:00、13:00、17:00、21:00补查。Windows任务以当前用户的普通权限运行，不需要管理员权限，用户需处于登录状态；电脑关机时不能运行，错过的任务可在条件恢复后补跑。

新建任务的首次触发设在至少十分钟后的下一次对应时刻，避免刚注册就补跑此前的计划；以后错过的计划仍按Windows任务设置处理。

| 动作 | 实际范围 |
| --- | --- |
| 签到 | 查询当天状态，未签时申请当天奖励 |
| 成长任务 | 自动接收可领取任务，只领取服务器已标记完成的奖励；不会替用户完成聊天、编程、邀请或分享 |
| 成长中心 | 领取旅行礼物、用已有补登卡补登、兑换已解锁连登奖励、使用抽奖机会、消耗已有能量开Buddy、派出空闲Buddy |
| 本地登录态 | 脚本读取本机登录文件，必要时调用WorkBuddy客户端的原生存储能力解密token；不要把这些内容发送给安装Agent |

程序默认业务地址是 `https://copilot.tencent.com`，但上游会采用本机登录文件里的自定义HTTPS endpoint，并未限定域名。此适配保留上游行为，不承诺请求一定只到腾讯域名。不要从他人处导入登录文件或修改认证地址来解决安装问题。

安装只复制固定版本文件并创建任务，不立即读取凭据或运行签到。它不改课程资料、教师权限、系统安全设置，也不安装Qoder相关功能。

## 一句话完成配置

> 把教师专家团、教师助手和自动签到Skill配置到我的教师项目，同时开启本机自动签到与成长中心。我了解它会使用补登卡、抽奖机会和能量。能自动完成的直接做，完成后核对任务与项目配置。

收到单独的“帮我安装教师项目”请求时，安装Skill文件与开启后台功能分别处理。使用者已明确选择上述完整功能，就不要重复索要确认。仅下载压缩包不视为同意持续操作该账号。

## 给接收端Agent的执行步骤

1. 确认是在接收者自己的Windows电脑上操作，能运行已有Python。安装器使用当前解释器旁的 `pythonw.exe`，缺失时报告具体依赖，不自动安装解释器或提权。
2. 从本Skill目录运行 `python scripts/manage_signin.py plan`，查看上游提交、预期源码哈希、稳定目录、两项任务和完整账号动作。plan不读取源码、凭据或真实调度器；安装时才实际验证哈希及依赖。只有在已有相应授权时运行 `install --mode signin-growth`。
3. 安装器使用独立任务名称和本机回执，保护其他安装及用户修改。它不执行包内上游PowerShell安装器，以免覆盖 `WorkBuddyAutoSignin` / `WorkBuddyGrowthPoll`。若机器上已有这些上游任务，不要再叠加一套；先读检查结果，交给用户决定沿用还是迁移。
4. 运行 `status`，检查任务实际动作、当前文件哈希及回执。这里只验证调度配置，不能写“已经领到积分”。需要实际验证时，以用户授权的一次本机运行及服务端返回为证，不能把离线测试结果当实机成功。
5. 把可见的下一次运行时间和日志位置交给用户。来源、动作或登录信息异常时停在具体错误，不索取token、不尝试绕过登录。

本版固定完整成长功能，没有可靠的只签到选项。上游说明中“删除轮询任务即可只签到”的建议不适用于该提交，因为每天的 `silent` 同样会运行成长中心。

## 停用与更新

对WorkBuddy说“卸载自动签到后台任务，保留日志”，执行 `python scripts/manage_signin.py uninstall`。卸载核对归属，只移除本套件的任务，不删除其他来源的任务，不递归删除运行目录或登录文件。仅在WorkBuddy中取消勾选或删除Skill，不能保证Windows计划任务已移除。

源码及日志保存在安装器报告的当前用户本地目录，避免下载文件移动后任务失效。重复安装同一版本会检查实际任务并复用；文件被修改、任务被替换或存在其他版本时，按结果处理冲突，不强行覆盖。上游更新需重新审阅并更新固定提交及哈希，本包不会自动跟随最新代码。
